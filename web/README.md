# ATOM HUNTER

Самостоятельная браузерная sci-fi игра: настраивай частоту, удерживай резонанс, собирай атомы и превращай свой улов в музыку. Игра работает локально, не требует аккаунта, сервера или внешних ключей; личный рекорд сохраняется в браузере.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

1. Установи зависимости: `npm install`.
2. Запусти разработку: `npm run dev`.
3. Для production-сборки: `npm run build`.
4. Для проверки кода: `npm run lint`.

## Игровое управление

- Передвигай ползунок частоты или используй кнопки рядом с ним.
- На клавиатуре ползунок управляется стрелками; Shift меняет частоту крупным шагом.
- Удерживай частоту в зоне резонанса до заполнения индикатора.
- Точность настройки и серия поимок увеличивают очки.
- После раунда можно прослушать свою последовательность атомов.

## Технологии

React, Vite, Web Audio API, Canvas 2D. Игровые данные сохраняются только в localStorage текущего браузера.

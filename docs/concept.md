# Resonator concept

## Definition

A resonator is a reusable system that allows a host application to bring a carrier signal into a controlled relationship with a target signal. The central action is not pressing a collection of buttons. It is tuning, observing, holding, and allowing a stable state to emerge.

## TD mapping

| TD phase | Resonator meaning |
|---|---|
| Potential | scattered frequencies and unresolved matter |
| Resonance | carrier approaches the target and coherence increases |
| Point Zero | stable match, compression, and preserved state |
| Transformation | resonance produces a new object, phase, sound, or event |

## First host application

REZONATOR uses six atomic elements: H, He, C, N, O, and Fe. Each element has a target frequency, visual identity, and sound identity. The host game owns the visual field and progression. The module owns the frequency relationship and resonance state.

## Boundary

The module should not contain:

- store-specific code;
- Android UI;
- a complete game loop;
- a particular visual style;
- philosophical claims presented as scientific facts.
